作者@晨钟酱Official

  1. 使用基于Chrome内核的浏览器打开本页面
  2. 通过USB数据线连接手机
  3. 开启手机中的USB调试
  4. 点击连接按钮
  5. 手机端出现授权提示，务必勾选“一律允许”，并同意调试
  6. 连接成功后即可进入工具，开搞！

若提示端口占用，请打开任务管理器结束本地运行的adb.exe，或关闭其他Webadb浏览器窗口
